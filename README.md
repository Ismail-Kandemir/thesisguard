# ThesisGuard

ThesisGuard is a professional web application for checking university thesis documents against thesis writing guidelines.

The first version targets Canakkale Onsekiz Mart University thesis rules.

## Tech Stack

- React
- TypeScript
- Vite

## Scripts

- `npm run dev`
- `npm run typecheck`
- `npm run lint`
- `npm run build`

This project is being developed step by step with an architecture-first approach.
