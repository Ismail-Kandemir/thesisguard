# Doğru Test Dokümanları

Bu klasörde mevcut validatorların tamamından başarılı geçmesi beklenen DOCX dosyaları yer alacaktır.

Dokümanların temel özellikleri:

- Yazı tipi: Times New Roman
- Yazı boyutu: 12 punto
- Satır aralığı: 1.5
- Paragraf hizalaması: İki yana yaslı

Test sonuçlarının karşılaştırılabilir olması için dokümanlarda yalnızca kontrollü ve kısa bir örnek içerik kullanılmalıdır.
