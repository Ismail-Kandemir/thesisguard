# Hatalı Yazı Tipi Test Dokümanları

Bu klasörde yalnızca yazı tipi hatası bulunan DOCX dosyaları yer alacaktır.

- Yazı tipi Times New Roman dışında bir değer olmalıdır.
- Yazı boyutu 12 punto olmalıdır.
- Satır aralığı 1.5 olmalıdır.
- Paragraflar iki yana yaslı olmalıdır.

Font Family validatorının başarısız, diğer mevcut validatorların başarılı olması beklenir.
