# Hatalı Yazı Boyutu Test Dokümanları

Bu klasörde yalnızca yazı boyutu hatası bulunan DOCX dosyaları yer alacaktır.

- Yazı tipi Times New Roman olmalıdır.
- Yazı boyutu 12 punto dışında bir değer olmalıdır.
- Satır aralığı 1.5 olmalıdır.
- Paragraflar iki yana yaslı olmalıdır.

Font Size validatorının başarısız, diğer mevcut validatorların başarılı olması beklenir.
