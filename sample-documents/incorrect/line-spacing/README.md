# Hatalı Satır Aralığı Test Dokümanları

Bu klasörde yalnızca satır aralığı hatası bulunan DOCX dosyaları yer alacaktır.

- Yazı tipi Times New Roman olmalıdır.
- Yazı boyutu 12 punto olmalıdır.
- Satır aralığı 1.5 dışında bir değer olmalıdır.
- Paragraflar iki yana yaslı olmalıdır.

Line Spacing validatorının başarısız, diğer mevcut validatorların başarılı olması beklenir.
